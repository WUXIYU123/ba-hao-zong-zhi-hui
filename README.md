# 八号总指挥：公关大逃亡

一个可直接导入微信开发者工具、也可在浏览器中试玩的 Canvas 微信小游戏原型。

## 玩法

- 点击“开始舆论攻防”，左右滑动在三条路线之间换道。
- 前半程选择“先道歉 / 绝非本意 / 请看剪辑”，你的选择会在之后变成同路线的回旋镖；不同回应会短暂改变赛道节奏。
- 中段进入“道歉三连”：按顺序穿过“承认 / 道歉 / 补救”路线，顺序错了会增加热度。
- 后段会出现“总指挥牌”，收集后可以调走一次后卫；命令越多，热度也会增加。
- 收集“补救卡”获得护盾；收集“龟壳”获得护盾，但短时间内转向变慢。
- 终点前会出现移动奖杯，追到它可以获得高分并降低热度。
- 难度分为“熟悉节奏、压力上升、舆论加速、终局冲刺”四段；45% 后明显加速刷障碍，72% 后后卫会偶尔封住两条路线，同屏上限升至 7、回应门间隔缩短至约 500–700 米。
- 回应门按跑道进度切换：0–18% 为采访回应，18%–45% 为道歉三连，45% 以后为总指挥模式；标题页和游戏内底部提示会持续说明当前目标。
- 热度达到 52、72、88 时会触发品牌撤退，赞助贴纸逐张掉落；热度爆表后有 8 秒冷却窗口。
- 跑完 50000 米，或口碑归零、冷却倒计时结束、赞助归零时结束。

## 导入

用微信开发者工具打开本目录，项目类型选择“小游戏”。公开版本使用 `touristappid`，真机预览或发布时在本地替换成自己的 AppID；个人项目配置不会提交到仓库。

## 浏览器试玩

浏览器试玩页为 `preview.html`，仓库根目录的 `index.html` 会自动跳转到它。在项目目录运行：

```bash
python3 -m http.server 8765
```

然后打开 `http://localhost:8765/`。这个页面也可以直接部署到 GitHub Pages。

## 公开仓库

- `game.js`、`game.json` 和 `project.config.json` 是小游戏源码与导入配置。
- `preview.html` 是不依赖微信开发者工具的浏览器试玩入口。
- `index.html` 是 GitHub Pages 的根目录入口，会跳转到浏览器试玩页。
- `project.private.config.json` 是本地开发工具配置，已加入 `.gitignore`。
